  - After `load_env`, apply the defaults `DATA_ROOT=/data APPDATA_ROOT=/opt/appdata PUID=1000 PGID=1000`, then `umask 002`.

- **`scripts/vm/00-bootstrap.sh`** (vars: `SYSROOT=""`, `DIR_MAPPING_ID=media-data`, `DATA_ROOT=/data`, `MEDIA_USER="${SUDO_USER:-}"` (dies if empty), `DOCKER_CODENAME` defaulting to `VERSION_CODENAME` from `${SYSROOT}/etc/os-release`):
  - Dies unless `ID=debian` in os-release. Warns if `VERSION_CODENAME != trixie`.
  - Steps, all through `run`/`run_sh`, each guarded:
    1. If `${SYSROOT}/etc/apt/sources.list.d/debian.sources` `Components:` lines lack `non-free-firmware`, run a `sed` that sets them to `main contrib non-free non-free-firmware`.
    2. `apt-get update`.
    3. `apt-get install -y firmware-intel-graphics intel-media-va-driver-non-free vainfo intel-gpu-tools qemu-guest-agent ca-certificates curl git`. If `APPLY=1` and `apt-cache show firmware-intel-graphics` fails, substitute `firmware-misc-nonfree`.
    4. Docker repo check. Only when `APPLY=1`: `curl -fsI https://download.docker.com/linux/debian/dists/$DOCKER_CODENAME/Release`. On failure, die "Docker repo has no $DOCKER_CODENAME; rerun with DOCKER_CODENAME=bookworm". In dry-run, print the curl as a DRY-RUN line.
    5. `install -m 0755 -d /etc/apt/keyrings`, then `curl -fsSL https://download.docker.com/linux/debian/gpg -o /etc/apt/keyrings/docker.asc`, then write `/etc/apt/sources.list.d/docker.sources` in deb822 format:
       ```
       Types: deb
       URIs: https://download.docker.com/linux/debian
       Suites: $DOCKER_CODENAME
       Components: stable
       Signed-By: /etc/apt/keyrings/docker.asc
       ```
       Skip if the file exists with the same content.
    6. `apt-get update`, then `apt-get install -y docker-ce docker-ce-cli containerd.io docker-buildx-plugin docker-compose-plugin`.
    7. `usermod -aG docker,render,video "$MEDIA_USER"`.
    8. `systemctl enable --now qemu-guest-agent`.
    9. `mkdir -p "$DATA_ROOT"`. If `${SYSROOT}/etc/fstab` lacks a line starting with `$DIR_MAPPING_ID `, append `$DIR_MAPPING_ID $DATA_ROOT virtiofs defaults,nofail 0 0`.
    10. `mount -a`.
    11. If `docker network inspect proxy` fails (or docker is absent), `docker network create proxy`.
  - Ends with log lines: reboot, then `sudo scripts/mkdirs.sh`, then `scripts/vm/verify.sh`.
  - Paths under `/etc` are prefixed with `${SYSROOT}` when read or written.
