Required interfaces/content structure:
- **`scripts/lib/common.sh`** (sourced, not executed; no shebang execution path; starts with a `# shellcheck shell=bash` directive). It defines:
  - `REPO_ROOT="$(cd "$(dirname "${BASH_SOURCE[0]}")/../.." && pwd)"`
  - `APPLY=0`
  - `log_info`/`log_warn`/`log_error`: `printf '[INFO] %s\n' "$*" >&2` and equivalents.
  - `die() { log_error "$*"; exit 1; }`
  - `parse_common_args "$@"`: `--apply` sets `APPLY=1`; `-h|--help` calls the caller's `usage` and exits 0; anything else calls `usage >&2; exit 2`.
  - `run() { if [[ $APPLY -eq 1 ]]; then "$@"; else printf 'DRY-RUN: %s\n' "$*"; fi; }`: prints to **stdout**.
  - `run_sh <string>`: for commands that need shell redirection. It prints `DRY-RUN: <string>` or executes `bash -c "<string>"`.
  - `require_root`: dies "must run as root with --apply" when `APPLY=1` and `EUID != 0`.
  - `require_cmd <names...>`: dies "missing required command: <name>".
  - `load_env`: if `$REPO_ROOT/.env` exists, read `KEY=VALUE` lines (skipping comments and blanks) and export only keys not already set in the environment. Never `source` the file blindly.
- **Script skeleton.** Every host script:
  - starts with `#!/usr/bin/env bash` and `set -Eeuo pipefail`;
  - runs `source "$(dirname "${BASH_SOURCE[0]}")/../lib/common.sh"`;
  - defines `usage()`, which prints the purpose, `Usage: <name> [--apply] [--help]`, and the env vars with defaults;
  - calls `parse_common_args "$@"`, then `load_env`, then `require_root`.
- **`scripts/ci/make-host-stubs.sh <dir>`** creates `<dir>` and executable stubs. Each stub logs its argv to `<dir>/calls.log`.
  - `zfs`: for `list -H -o name tank`, print `tank` and exit 0. For `list -H -o name tank/data` or `tank/backups`, exit 1 (absent). For `list -H -r -o name tank/data`, print nothing and exit 0. Anything else exits 0.
  - `lspci`: for `-Dnn -d 8086:56a5`, print `0000:03:00.0 VGA compatible controller [0300]: Intel Corporation DG2 [Arc A380] [8086:56a5] (rev 05)`. For `-Dnn -d 8086:4f92`, print `0000:04:00.0 Audio device [0403]: Intel Corporation DG2 Audio Controller [8086:4f92]`. Anything else prints nothing.
  - `qm`: `status <id>` prints `Configuration file 'nodes/pve/qemu-server/<id>.conf' does not exist` to stderr and exits 2. Anything else exits 0.
  - `pvesh`: `get /cluster/mapping/dir/<id>` exits 1 (absent). Anything else exits 0.
  - `pveversion`: prints `pve-manager/9.0.6/49c767b70aeb6660 (running kernel: 6.14.8-2-pve)`.
  - `hostname`: prints `pve`.
- **`00-zfs-datasets.sh`** (vars: `POOL=tank`):
  1. `require_cmd zfs`.
  2. Die if `zfs list -H -o name "$POOL"` fails: "pool $POOL not found".
  3. If `$POOL/data` exists: list children with `zfs list -H -r -o name "$POOL/data"`, excluding itself. If any exist, log the error "child datasets break hardlinks: …" and exit 1. Otherwise log "exists" and skip the create.
  4. Otherwise `run zfs create -o recordsize=1M -o compression=lz4 -o atime=off -o xattr=sa "$POOL/data"`.
  5. If `$POOL/backups` is absent: `run zfs create -o compression=zstd "$POOL/backups"`.
  6. Log the next step: "run 10-iommu-vfio.sh".
- **`10-iommu-vfio.sh`** (vars: `GPU_PCI` optional; `GPU_ID=8086:56a5`; `AUDIO_ID=8086:4f92`; `SYSROOT=""`):
  1. `require_cmd lspci`.
  2. Detect the GPU: `lspci -Dnn -d "$GPU_ID"`, first field. Zero matches: die "no Arc A380 ($GPU_ID) found; set GPU_PCI". More than one match without `GPU_PCI`: die, listing them. Log the detected address.
  3. Detect the audio device the same way. If it's missing, only warn and use just the GPU ID in `ids=`.
  4. CPU vendor from `${SYSROOT}/proc/cpuinfo`: `GenuineIntel` gives params `intel_iommu=on iommu=pt`; `AuthenticAMD` gives `iommu=pt` (AMD IOMMU is on by default). Otherwise die.
  5. Bootloader:
     - If `${SYSROOT}/etc/kernel/cmdline` exists: append the missing params to its single line, using `run_sh` with a `sed -i` that appends only params not already present, then `run proxmox-boot-tool refresh`.
     - Else if `${SYSROOT}/etc/default/grub` exists: add the missing params inside `GRUB_CMDLINE_LINUX_DEFAULT="…"` via `sed`, then `run update-grub`.
     - Else die "no supported bootloader config found".
     - In both cases compute the missing params first. If none are missing, log "cmdline already configured" and skip the edit and refresh.
  6. `${SYSROOT}/etc/modules-load.d/vfio.conf` should contain exactly the lines `vfio`, `vfio_iommu_type1`, `vfio_pci`. Write it with `run_sh "printf … > path"` only if the content differs.
  7. `${SYSROOT}/etc/modprobe.d/vfio.conf` should contain exactly:
     ```
     options vfio-pci ids=<GPU_ID>,<AUDIO_ID>
     softdep i915 pre: vfio-pci
     softdep xe pre: vfio-pci
     softdep snd_hda_intel pre: vfio-pci
     ```
     Write it only if the content differs.
  8. If any of steps 5–7 changed something: `run update-initramfs -u -k all`, then log a WARN "reboot required", followed by the check commands: `dmesg | grep -e DMAR -e IOMMU` and `lspci -nnk -s <GPU_PCI>` should show `Kernel driver in use: vfio-pci`.
- **`20-create-vm.sh`** (vars and defaults exactly as in the spec: `VMID=200 VM_NAME=media-01 VM_CORES=8 VM_MEMORY=20480 VM_STORAGE=local-zfs VM_DISK_GB=64 VM_BRIDGE=vmbr0 ISO=local:iso/debian-13-amd64-netinst.iso DIR_MAPPING_ID=media-data POOL=tank GPU_PCI` auto-detected as in 10):
  1. `require_cmd qm pvesh pveversion lspci`.
  2. Parse `pveversion`, e.g. `pve-manager/9.0.6/…`, into major.minor. Die if below 8.4.
  3. Die if `qm status "$VMID"` succeeds: "VMID $VMID already exists".
  4. If `pvesh get /cluster/mapping/dir/$DIR_MAPPING_ID` fails: `run pvesh create /cluster/mapping/dir --id "$DIR_MAPPING_ID" --map "node=$(hostname),path=/$POOL/data"`.
  5. Run `qm create`. Emit it as a single `run qm create …` invocation with exactly these args, in order:
     `"$VMID" --name "$VM_NAME" --machine q35 --bios ovmf --cpu host --cores "$VM_CORES" --memory "$VM_MEMORY" --balloon 0 --scsihw virtio-scsi-single --scsi0 "$VM_STORAGE:$VM_DISK_GB,iothread=1,discard=on,ssd=1" --efidisk0 "$VM_STORAGE:1,efitype=4m,pre-enrolled-keys=0" --net0 "virtio,bridge=$VM_BRIDGE" --ide2 "$ISO,media=cdrom" --boot "order=scsi0;ide2" --ostype l26 --agent enabled=1 --onboot 1`
  6. `run qm set "$VMID" --hostpci0 "$GPU_PCI,pcie=1"`.
  7. `run qm set "$VMID" --virtiofs0 "$DIR_MAPPING_ID,cache=auto"`.
  8. Log the next steps: start the VM, install Debian 13, follow `docs/runbooks/02-vm-bootstrap.md`. Add a fallback note: if the guest's i915 fails to initialise, run `qm set $VMID --vga none` and `--hostpci0 $GPU_PCI,pcie=1,x-vga=1`.
