- crowdsec-ban: start a throwaway curl container on the proxy network, read its IP, `cscli decisions add --ip <ip> --duration 2m --reason verify-edge`, poll https://requests.$DOMAIN/ (resolved to traefik) for up to 30 s until 403, then `cscli decisions delete --ip <ip>` and remove the container in a trap. Private IPs pass geoblock (allowLocalRequests), so the 403 proves CrowdSec.
