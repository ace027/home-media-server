<objective>
Build the two-step config restore:
1. The host script streams only the allow-listed old app configs from the archive into VM staging over ssh.
2. The VM script checks the staged databases, swaps them into `/opt/appdata` with rollback, fixes Plex and SABnzbd offline, and records a baseline.

Purpose: keep settings, history and Plex watch state (Phase 2 criterion 5) without leaking secrets or starting any app on the old paths.
Output: `scripts/host/30-push-appdata.sh`, `scripts/vm/10-restore-appdata.sh`, `scripts/ci/test-restore.sh` and synthetic fixtures.
</objective>

Create `scripts/vm/10-restore-appdata.sh` (executable). Follow the spec contract "`scripts/vm/10-restore-appdata.sh`", apply steps 1–9, in order.

**Setup:**
- Local flag parsing for `--stage <ts>` and `--rollback <ts>`; both are validated against `^[0-9]{8}-[0-9]{6}$`.
- `load_env`. `APPDATA_ROOT` and `DATA_ROOT` go through `require_safe_path`; `PUID`/`PGID` must be numeric.
- `require_cmd sqlite3 jq docker setpriv`. With `--apply`, run `require_root`.

**Define:**
```
SERVICES=(plex seerr tautulli sonarr sonarr-anime radarr lidarr prowlarr sabnzbd)
FRESH=(sonarr-4k radarr-4k jellyfin)
DC=(docker compose --project-directory "$REPO_ROOT")
```

**Preconditions (all modes):**
- Running services: `"${DC[@]}" ps --status running --services`. If any of `SERVICES` is listed, `die "stop first: docker compose stop <list>"`.
- Stage: `$APPDATA_ROOT/.staging/$TS` must exist. When `--stage` is absent, `TS` is the newest entry. The top-level entries must be a subset of `SERVICES`.
- Symlinks: for every symlink under the stage (`find -type l`), `realpath -m` must stay under the stage, else `die`.
- Old roots: if any of `$DATA_ROOT/shows`, `$DATA_ROOT/movies` or `$DATA_ROOT/anime` exists, `die` naming it (a scan of an existing old root would drop file records before the remap; see spec Failure Modes).

**Apply (restore mode):**
1. **Integrity check**, even in dry-run because it is read-only. For each `<svc>/<name>.db` in `sonarr/sonarr.db sonarr-anime/sonarr.db radarr/radarr.db lidarr/lidarr.db prowlarr/prowlarr.db` that exists in the stage:
   ```
   setpriv --reuid="$PUID" --regid="$PGID" --init-groups sqlite3 -readonly "<db>" 'PRAGMA integrity_check;'
   ```
   The result must equal `ok`, else `die "integrity check failed: <svc>"`. Nothing has been moved at this point. If the process isn't root in dry-run, call `sqlite3` directly instead.
2. **Swap.** First, unconditionally, `run mkdir -p -m 700 "$APPDATA_ROOT/.rollback/$TS"` (step 5 moves `sabnzbd/admin` there even on a first restore where no target dir exists). Then, for each service in the stage, through `run`:
   - if `$APPDATA_ROOT/<svc>` exists and is empty, `rmdir` it;
   - else if it exists, `mv` it into `.rollback/$TS`;
   - then `mv -T "$STAGE/<svc>" "$APPDATA_ROOT/<svc>"`.
3. **Ownership:** `run chown -R "$PUID:$PGID"` and `run chmod 700` on each restored dir; `run find <dir> -name '*.pid' -delete`.
4. **Plex prefs:** `P="$APPDATA_ROOT/plex/Library/Application Support/Plex Media Server/Preferences.xml"`.
   - If it exists: use `run_sh` with a sed that replaces `autoEmptyTrash="[^"]*"` with `autoEmptyTrash="0"`, or, if the attribute is absent, inserts ` autoEmptyTrash="0"` before the final `/>` of the `<Preferences` element. With `--apply`, confirm with `grep -q 'autoEmptyTrash="0"'`.
   - `TranscoderTempDirectory`: if the attribute is present and its value doesn't start with `/config` or `/transcode`, log `[WARN]` with the value and delete the attribute via sed.
   - If the file is missing: `log_warn "Preferences.xml missing; set 'Empty trash automatically' off in the Plex UI before any scan"`.
5. **SAB:** in `$APPDATA_ROOT/sabnzbd/sabnzbd.ini`, `run_sh` a sed that sets `download_dir = /data/usenet/incomplete` and `complete_dir = /data/usenet/complete` (anchored at the start of the line). Then `run mv "$APPDATA_ROOT/sabnzbd/admin" "$APPDATA_ROOT/.rollback/$TS/sabnzbd-admin"` if it exists.
6. **UrlBase/Port:** for each `config.xml` of sonarr, sonarr-anime, radarr, lidarr and prowlarr, read `<UrlBase>` and `<Port>` with `sed -n`. Warn if `UrlBase` is non-empty or `Port` isn't the default (8989/8989/7878/8686/9696), and collect the warning into the baseline's `warnings` array.
7. **Fresh services:** for each service in `FRESH` that is missing, `run install -d -m 700 -o "$PUID" -g "$PGID" "$APPDATA_ROOT/<svc>"`.
8. **Baseline:** with `--apply`, run the spec counts as `PUID` in `-readonly` mode (`plex_watched` = -1 plus a warning on error; use the spec's owner-only movies+episodes query), also write the spec's `baseline-ids/<svc>.txt` files, then `install -d -m 700 -o "$PUID" -g "$PGID" "$APPDATA_ROOT/.migration"`, write `$APPDATA_ROOT/.migration/baseline.json` with `jq -n --arg/--argjson` and `umask 077`, and `chown "$PUID:$PGID"` it. The later scripts (`25-arr-wire`, `30-split-4k`, `verify-media`) run as `media` and must be able to read the baseline and write plan/manifest files into `.migration/`. Dry-run prints `DRY-RUN: write baseline …`.
9. **Cleanup:** `run rmdir "$STAGE"`.

**Rollback mode (`--rollback <ts>`):** for each dir in `$APPDATA_ROOT/.rollback/<ts>/` except `sabnzbd-admin`:
- move the current `$APPDATA_ROOT/<svc>` to `$APPDATA_ROOT/.rollback/<ts>-undone/<svc>`;
- `mv -T` the saved dir back;
- move `sabnzbd-admin` back to `sabnzbd/admin`.

The same "services not running" precondition applies. The script finishes with `[INFO] rolled back <ts>`.

**Output:** `[INFO]` per step. The last line is `[INFO] restored <n> services from <ts>; next: docker compose up -d sonarr sonarr-anime radarr lidarr` (restore mode).
